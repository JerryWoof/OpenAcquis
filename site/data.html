Data and API

Everything on this site is plain files you can download or fetch: no key, no server, no rate limit beyond GitHub's. The data is CC-BY-4.0; please cite OpenAcquis and the sources below.

Dataset: provision-level links

Links between EU directive provisions and national provisions that come from official correlation tables (attached by the Czech and Slovak governments to their bills) or from human review. Unreviewed machine suggestions are not in it. A link says what a government listed or a reviewer confirmed; it does not say a provision is transposed correctly.

  • links.csv: one row per link (spreadsheet-safe)
  • links.jsonl: the same as JSON lines
  • reviews.jsonl: every human review record, including rejections
  • datapackage.json: Frictionless Data Package with field descriptions, licence and sources
  • README.md: counts, citation and attribution

Static JSON API

Versioned JSON files under api/v1/: directives, notified measures, article × country matrices, alignments (machine candidates, without texts), dataset links, review records, and the EU and national provision texts each stored once. Start from api/v1/index.json; it lists every file. Described by OpenAPI 3.1 and JSON Schemas (list of schemas). Documentation: docs/api.md.

curl -s https://jerrywoof.github.io/OpenAcquis/api/v1/index.json | jq '.data.counts'
curl -s https://jerrywoof.github.io/OpenAcquis/api/v1/directives/32022L2557/sk/links.json | jq '.data.links[0]'

Change feed

A weekly job checks the directives (amendments, corrigenda, consolidated versions), the national measures notified for them, and the main national acts on e-Sbírka, Slov-Lex, RIS and gesetze-im-internet.de. Changes are published as an Atom feed and as GitHub issues labelled change-alert.

Command line

git clone https://github.com/JerryWoof/OpenAcquis && cd OpenAcquis && pip install -e .
openacquis directives          # the registry: main act per directive and country
openacquis eval cer-sk         # score matching against an official correlation table
openacquis dataset build       # rebuild the dataset locally

Not legal advice. Official correlation tables describe government bills; machine suggestions are unreviewed. None of the data says whether a member state transposed a directive correctly.

Directive texts and measures: EUR-Lex / CELLAR, © European Union, https://eur-lex.europa.eu (reuse under Commission Decision 2011/833/EU). National law: e-Sbírka (CZ), Slov-Lex (SK), RIS (AT), gesetze-im-internet.de (DE). Correlation tables: psp.cz, nrsr.sk. Code: MIT; data: CC-BY-4.0.
